# outreach-clock-time

**Outreach Clock** is a single-page tool that shows the live local time (with AM/PM) in agency hubs across the US, Australia and the UK, compared with Bangladesh time (BDT), so you can time cold outreach emails.

- **Cities:** New York, Chicago, Denver, Phoenix, Los Angeles, Sydney, Brisbane, Adelaide, Perth and London.
- **BDT comparison:** each city shows how far it is ahead of or behind Bangladesh, and its 8–11 AM window in BDT.
- **Daylight saving:** detected automatically. Each city shows whether daylight saving is on, off or not observed, and the BDT difference updates when clocks change.
- **Send status:** Best time (8–11 AM weekdays), Business hours (11 AM–5 PM), Early (6–8 AM), After hours or Weekend.
- **Schedule send:** pick a recipient city and their local time, and it tells you the BDT time to schedule the email.

## Usage

Open `index.html` in a browser. It has no build step and no dependencies. To host it, enable GitHub Pages for this repository (Settings → Pages → deploy from the `main` branch).
